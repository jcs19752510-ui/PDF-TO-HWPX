[HWPX 참조 파일 만들기 안내]  한컴오피스 한글에서 아래 4개를 각각 저장해 이 폴더에 넣어 주세요.
저장 형식: 파일 > 다른 이름으로 저장 > 파일 형식 "한글 문서(*.hwpx)"

1) 01_빈문서.hwpx     : 새 문서를 아무것도 입력하지 않고 그대로 저장
2) 02_글자서식.hwpx   : 아래 내용을 입력해서 저장
     - 첫 줄: "일반 글자 ABC 123 가나다"
     - 둘째 줄: 굵게 + 글자 크기 20pt로 "굵은 큰 글자"
     - 셋째 줄: 가운데 정렬로 "가운데 정렬 문단"
     - (엔터로 문단 3개 이상)
3) 03_표.hwpx         : 2행 x 2열 표를 넣고 각 칸에 "A1" "B1" "A2" "B2" 입력 후 저장
4) 04_그림.hwpx       : 그림 1개(작은 jpg 또는 png)를 넣고 그 아래 "그림 아래 글" 입력 후 저장

* 문서 편집 중 한글에 글꼴 대체 알림이 나와도 그대로 저장하면 됩니다.
* 개인정보가 든 그림/글은 넣지 마세요. 연습용 내용이면 충분합니다.
* 한글 버전(도움말 > 한글 정보)을 대화창에 알려 주시면 더 좋습니다.
