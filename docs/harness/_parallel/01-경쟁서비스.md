- 담당 축: 유사 서비스/경쟁 환경
- 조사 시점: 2026-09-27 (웹 검색 기준, 각 항목에 개별 확인 시점 병기)
- 조사 범위: PDF를 한글(HWP/HWPX)로 변환하는 기능을 제공하는 실존 서비스/제품 4종 (요구된 최소 3개 이상 충족)

## 조사 대상 개요

| 서비스 | 유형 | 배포 형태 | 비고 |
|---|---|---|---|
| 한컴오피스 한PDF (한글과컴퓨터) | 오피스 번들 기능 | 데스크톱(윈도우) + 구독형 클라우드(한컴독스) | 국내 표준 오피스와 동일 벤더 |

## 1. 한컴오피스 한PDF (한글과컴퓨터)

- **기능**: 한글(아래아한글) 프로그램의 [파일 → PDF를 오피스 문서로 변환하기] 메뉴를 통해 PDF를 hwp/hwpx/docx/pptx/xlsx 등으로 변환. OCR 사용 여부, 레이아웃 유지 여부, 이미지 DPI 등 옵션 설정 가능.
  - 출처: 한컴 공식 도움말 https://help.hancom.com/hoffice100/ko-KR/Hpdf/file/open/open(pdf).htm , https://help.hancom.com/hoffice130/ko-KR/Hpdf/convert/to_hwp.htm (확인 시점: 2026-09-27)
- **강점**
  - 변환 결과물을 곧바로 한글(HWP/HWPX) 네이티브 편집기에서 열어 편집 가능 (타 벤더 대비 자체 포맷 호환성 최상 — 추정, 동일 벤더이므로 구조적으로 유리하나 정량적 비교 자료는 확인 못함).
  - hwpx로 직접 저장 가능 (2022 버전 기준 hwp/hwpx/docx/show/pptx/cell/xlsx/txt/rtf/html/이미지 등 지원). 출처: 나무위키 "한컴오피스 한PDF" https://namu.wiki/w/한컴오피스%20한PDF (확인 시점: 2026-09-27, 나무위키는 위키 특성상 2차 출처이며 교차검증 권장)
- **약점/한계**
  - 한PDF 자체는 "북마크 기능 없음", "페이지 이동/삭제/삽입 기능 없음", "텍스트·그림 삽입 기능 없음" 등 PDF 편집기로서는 기능 제한적 (출처: 위 나무위키 문서, 2026-09-27 확인). 단, 이는 PDF 편집 기능 관점이며 PDF→HWP 변환 자체의 품질과는 별개.
  - 변환 품질 관련 정량 데이터(정확도 %, 실패율 등)는 공식 자료에서 확인하지 못함 → **확인 필요**.
- **가격**
  - 한컴오피스는 2022년경부터 구독형(한컴독스)으로 전환. 개인용 구독료 월 6,900원, 연 49,000원 (출처: ZDNet Korea, "구독 모델로 전환하는 한컴오피스, 뭐가 달라지나" https://zdnet.co.kr/view/?no=20220928155736, 기사 시점 2022-09-28 — **주의: 이 가격은 2022년 시점 기사 기준이며 2026년 현재 가격과 다를 수 있음, 최신 가격은 확인 필요**). 영구 라이선스 패키지 병행 판매 여부 및 현재가는 공식 스토어(hancom.com) 확인 필요.
  - 한PDF가 한컴오피스 패키지에 포함되는지, 별도 과금되는지 명확한 가격 페이지를 찾지 못함 → **확인 필요**.

## 2. 알PDF 알PDF (이스트소프트/알툴즈, ALPdf)

- **기능**: 데스크톱 설치형 PDF 편집·변환 프로그램. hwp/hwpx를 포함해 약 18종 포맷으로 변환 지원, OCR로 스캔 이미지 내 텍스트도 인식·변환.
  - 출처: 알툴즈 공식 제품 페이지 https://altools.co.kr/product/ALPDF , 소프트2000 블로그 https://www.soft2000.com/14234 (확인 시점: 2026-09-27)
- **강점**
  - 오프라인(로컬) 처리 — 문서를 서버에 업로드하지 않아 민감 문서 처리에 유리 (본 프로젝트가 "로컬 변환"을 지향한다면 직접적인 경쟁/참고 지점).
  - OCR 내장으로 스캔본 PDF도 처리 시도 가능.
- **약점/한계**
  - 개인용 정가/구독 여부를 공식 구매 페이지(secure.altools.co.kr/Buy/ALPDF.aspx)에서 직접 확인했으나, 해당 페이지에는 기업용·공공기관용·교육기관용 라이선스만 게시되어 있고 개인용 가격 정보는 없었음 (확인 시점: 2026-09-27). → **개인용 가격 확인 필요** (문의처: altools@estsoft.com, 1544-8209로만 안내).
  - 기업용 라이선스는 2개 이상 구매 시 1개당 92,000원부터 시작 (출처: 다나와/디바이스마트 등 유통 페이지 종합, 확인 시점: 2026-09-27). 개인 1인 단위 가격과는 다를 수 있음.
  - 변환 품질(레이아웃/표 보존율)에 대한 사용자 리뷰를 구체적으로 찾지 못함 → **확인 필요**. 다만 아래 "공통 한계" 절의 문제(표/수식 깨짐)는 PDF→HWP 변환 전반의 구조적 문제이므로 알PDF도 예외가 아닐 가능성이 높음 (추정).

## 3. HiPDF (Wondershare)

- **기능**: 브라우저에서 PDF를 업로드하면 서버에서 HWP로 변환해주는 온라인 툴. OCR로 스캔 PDF도 지원한다고 광고.
  - 출처: HiPDF 한국어 페이지 https://www.hipdf.com/kr/pdf-to-hwp.html (확인 시점: 2026-09-27)
- **강점**
  - 설치 불필요, 무료로 즉시 사용 가능 (웹 접근성 최고).
- **약점/한계**
  - 무료 요금제는 하루 2회 작업, 파일당 10MB·50페이지로 제한 (출처: HiPDF 공식/가격 비교 자료 종합, 확인 시점: 2026-09-27).
  - 유료 Pro Web 요금제는 월 $6(연간 결제 시 할인)로 파일 제한 완화(최대 100MB·2000페이지)라는 정보와, 별도로 "$39.99까지의 3가지 유료 요금제"라는 정보가 검색됨 — **두 출처의 구체적 금액 구성이 상충함**. 정확한 현재 요금표는 https://www.hipdf.com/pricing 원문 확인 필요(확인 필요로 표기).
  - **서버 업로드형이므로 문서를 외부 서버에 전송해야 함** — 개인 문서(계약서, 이력서 등)를 다루는 본 프로젝트의 "로컬 변환" 지향과는 정반대 트레이드오프. 보안/프라이버시 민감 사용자에게는 약점.
  - 실사용 리뷰: PDF→Word 변환에서 "표가 깨지고 이미지 위치가 틀어지고 텍스트가 사라짐", "기본적인 OCR 기능도 없다시피 하고 텍스트 편집 도구가 거의 쓸모없다"는 부정적 리뷰 존재(출처: aidetectplus.com 리뷰 블로그 https://aidetectplus.com/blog/hipdf-review , 확인 시점: 2026-09-27). 단, 이는 PDF→Word 사례이며 PDF→HWP 자체에 대한 리뷰는 찾지 못함(품질이 유사할 것이라는 추정만 가능). 반대로 "변환 후 깨끗하게 유지되고 오류가 없었다"는 긍정 리뷰도 함께 확인되어 **평가가 상충함** — 이는 문서 유형/복잡도에 따라 편차가 크다는 방증으로 해석됨.

## 4. 폴라리스오피스 툴즈 (Polaris Office)

- **기능**: 웹 기반 HWPX 변환 도구. HWPX↔HWP, HWP→PDF 등 다양한 변환 지원. WebAssembly 기술로 "파일을 서버에 업로드하지 않고 기기 내에서 처리"한다고 명시.
  - 출처: 폴라리스오피스 비즈니스 블로그 https://www.polarisoffice.com/business-blog/tools-hwpx-converter/ , https://www.polarisofficetools.com/hwp/convert/pdf (확인 시점: 2026-09-27)
- **강점**
  - 무료, 회원가입/설치 불필요.
  - **로컬(브라우저 내) 처리를 표방** — HiPDF류 서버 업로드형과 달리 프라이버시 이점을 마케팅 포인트로 내세움. 본 프로젝트가 "로컬 변환"을 강점으로 삼으려 한다면 가장 근접한 포지셔닝의 경쟁자.
  - PC 웹/안드로이드/iOS 등 멀티플랫폼 지원.
- **약점/한계**
  - 이 블로그 글 자체가 폴라리스오피스의 자사 홍보 콘텐츠이므로, 변환 품질에 대한 객관적(제3자) 평가는 별도로 찾지 못함 → **확인 필요**.
  - 웹 기반이므로 오프라인 완전 독립 실행은 불가(브라우저/인터넷 필요, WebAssembly 실행을 위한 페이지 로드는 필요).

## 공통으로 확인된 PDF→HWP/HWPX 변환의 구조적 한계 (전 서비스 공통 리스크)

- **표(테이블) 깨짐, 레이아웃 뒤틀림**: 국내 커뮤니티(클리앙 등)에서 반복적으로 보고됨. "표가 깨지고 페이지 레이아웃이 엉망이 된다"는 불만이 다수 확인됨. 출처: 클리앙 게시판 다수 스레드 종합 검색 결과 (확인 시점: 2026-09-27). 개별 스레드 예: https://www.clien.net/service/board/park/12666853
- **수식(수학 기호) 깨짐**: PDF는 수식의 겉모양만 저장하고 구조적 의미(분수, 첨자 관계 등)를 갖지 않아, 변환기가 이를 역추론해야 하는 근본적 어려움이 있음. 실사용자는 "PDF 툴이나 온라인 컨버터를 다 써봤는데 다 깨진다"고 보고했고, 전문가 답변은 "근본적 해결책이 없고, 캡처해서 이미지로 넣거나 수식을 직접 재작성하는 수밖에 없다"였음. 출처: 클리앙 https://www.clien.net/service/board/kin/15421224 (확인 시점: 2026-09-27), 관련 설명 블로그 "PDF 수식 HWP 변환, 왜 어려울까?" https://blog.xn--hy1bk3ua490d.com/123 (한글 유니코드 도메인, 확인 시점 2026-09-27)
- **폰트 깨짐/텍스트 누락**: 특히 한글 및 다국어 혼용 문서에서 자주 발생한다는 언급이 다수 도구 안내 문서에서 공통적으로 나타남(출처: Wondershare 자료 리커버릿 https://recoverit.wondershare.kr/damaged-document-file-repair/hwp-pdf-file-recovery-tips.html, 확인 시점: 2026-09-27). 이는 벤더 자체 안내이므로 다소 일반론적 서술일 수 있어 참고용으로만 사용.

## 이 프로젝트가 차별화할 수 있는 지점 (시사점)

1. **로컬/오프라인 처리 + 무료 + 개인용 사용성 삼박자를 동시에 충족하는 제품이 드묾.** 한PDF는 로컬이지만 유료 구독 오피스 패키지 전제, 알PDF는 로컬이지만 개인용 가격이 불투명(확인 필요)하고 기업용 중심 마케팅, HiPDF는 무료이지만 서버 업로드형(프라이버시 트레이드오프), 폴라리스는 무료+로컬(WebAssembly)이지만 HWPX 변환에 특화된 '가벼운 유틸리티' 포지셔닝이라 범용 PDF(스캔본, 서식, 보고서 등) 대응력은 제3자 검증 자료가 없음(확인 필요). → 개인 사용자가 "내 문서를 어디에도 업로드하지 않고, 무료로, 간단히" 쓸 수 있는 지점은 상대적으로 비어 있을 가능성이 있음(다만 폴라리스와 정면 포지셔닝이 겹칠 수 있어 실제 사용성 비교는 별도 검증 필요).
2. **표/수식/레이아웃 깨짐은 업계 공통의 구조적 난제이므로, "완벽 변환"을 약속하기보다 어떤 요소(표/이미지/수식 중 무엇)를 우선 보존하고 무엇은 한계로 명시할지 기대치 관리 전략이 필요.** 경쟁 제품들도 이 문제를 완전히 해결하지 못했다는 점이 여러 출처에서 확인됨.
3. **2026년 공공기관 HWPX 의무화(아래 "타 축 참고" 참조)로 HWPX 변환 수요가 구조적으로 늘어날 시점** — 기존 경쟁 서비스 다수가 HWP 중심이거나 HWPX를 부가 기능으로만 지원하므로, HWPX 네이티브 대응을 전면에 내세우면 시의성 있는 차별화가 가능.
4. HiPDF 리뷰에서 확인된 "표 깨짐/이미지 위치 이탈/텍스트 소실" 같은 구체적 실패 유형은 이 프로젝트의 품질 목표(예: 표/이미지 보존율 기준) 수립 시 실제 벤치마크 항목으로 참고할 만함.

## 상충되는 정보 (요약)

- HiPDF 유료 요금제 금액 구성(월 $6 Pro Web vs. 최대 $39.99 요금제 존재)이 서로 다른 출처에서 다르게 서술됨 — 원문 가격표 재확인 필요.
- HiPDF 변환 품질에 대해 "표/이미지/텍스트 깨짐이 심하다"는 부정 리뷰와 "깨끗하게 유지되고 오류 없다"는 긍정 리뷰가 동시에 확인됨 — 문서 복잡도/유형에 따른 편차로 추정되나 근거는 불충분.

## 확인하지 못한 부분 (확인 필요 목록)

- 한PDF의 PDF→HWP/HWPX 변환 정확도에 대한 정량적/제3자 평가 자료
- 알PDF 개인용 가격(구독/영구), 무료체험 제공 여부
